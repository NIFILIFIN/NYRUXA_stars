# NYRUXA_stars — генератор звёзд

Интерактивный генератор уникальных звёзд в браузере: одна страница, один HTML-файл, без сборки и зависимостей. Каждая звезда детерминирована кодом — один и тот же код всегда даёт одну и ту же звезду, её визуал, параметры и историю.

**Демо:** откройте `index.html` в браузере.

---

## Возможности

- **Детерминированная генерация по коду.** Код из 6 символов (`A–Z`, `2–9`) однозначно задаёт звезду. Ссылка вида `?s=ABC123` открывает её сразу.
- **17+ архетипов звёзд:** главная последовательность (O–M), красные гиганты, сверхгиганты, гипергиганты, субкарлики, звёзды Вольфа–Райе, углеродные, контактные двойные, вспыхивающие, голубые блуждающие, протозвёзды, пульсары, магнетары, чёрные дыры, симбиотические системы, гамма-всплески, пульсары с глитчем, звёзды с осколочным диском.
- **События:**
  - **Мифическая чёрная дыра** — шанс `1 : 100 000`, особая вспышка, звук и тост.
  - **Сверхновая** — шанс `1 : 2 000`, короткая анимация вспышки, затем звезда становится компактным остатком (нейтронная звезда или чёрная дыра).
- **Созвездия** — с шансом `1 : 50` звезда входит в созвездие; на фоне рисуются линии к соседям.
- **Скрытые коды-пасхалки:** `SUN`, `SIRIUS`, `VEGA`, `POLARIS`, `BETELGEUSE`, `NYX` — реальные аналоги и одна мифическая дыра.
- **Коллекция** — сохранение до 60 звёзд в `localStorage`, фильтр по редкости, ленивая отрисовка миниатюр.
- **Сравнение** — выберите две звезды в коллекции и нажмите «Сравнить».
- **Тонкая настройка** — яркость, насыщенность, скорость, режим «меньше анимации».
- **Экспорт** — PNG текущей звезды, копирование кода, копирование ссылки на звезду.
- **Звук** — синтезированный аккорд при рождении звезды (можно выключить).
- **Доступность** — учитывает `prefers-reduced-motion`, есть клавиатурные хоткеи.

## Управление

| Действие | Мышь / тап | Клавиатура |
| --- | --- | --- |
| Новая звезда | кнопка «Родить новую звезду» | `Space`, `R` |
| Сохранить | кнопка «Сохранить» | `S` |
| Скопировать код | кнопка «Скопировать код» | `C` |
| Пауза / продолжить | двойной тап по канвасу | `P` |

## Как это работает

1. **Код → сид.** Из строки кода считается 32-битный хеш (FNV-1a), из него — детерминированный ГПСЧ (mulberry32).
2. **Архетип.** По сиду выбирается класс звезды и архетип; отдельные «событийные» роллы (мифическая дыра, сверхновая, созвездие) считаются от производных сидов, чтобы не влиять на основной выбор.
3. **Параметры.** Температура, масса, радиус, светимость, возраст, расстояние, планеты, кольца, поверхность, вспышки — всё выводится из сида.
4. **Рендер.** `canvas 2D` рисует звезду и окружение в реальном времени; параметры анимации тоже берутся из сида, поэтому звезда «двигается по-своему».
5. **Сохранение.** В `localStorage` хранятся только коды — при открытии звезда восстанавливается из кода один в один.

## Совместимость

Современные браузеры: Chrome, Edge, Firefox, Safari (десктоп и мобильные). Требуется `canvas 2D`, `localStorage`, `requestAnimationFrame`; `AudioContext` и `IntersectionObserver` опциональны.
